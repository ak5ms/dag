# Generic projection and producer fusion benchmark

The complete benchmark table is generated by the controlled local harness and committed alongside the implementation. It compares the untouched branch snapshot with the optimized compiler using alternating subprocess order, one warmup, identical input files, one native thread, and exact/allclose output validation.

The benchmark covers:

- column sum/mean/std projections;
- stateless row-PnL Sharpe;
- 4-, 16-, and 32-candidate batched GP scoring;
- 4- and 8-candidate stateful batches;
- complete-case EWM co-moment algebra;
- a cross-family EWM/cumsum sharing graph;
- independently generated depth-3–5 typed-GP formulas;
- joint compilation of 4 and 8 deep typed-GP candidates.

Exact run arrays, stage counts, formulas, checksums, and summary statistics are in `PROJECTION_FUSION_BENCHMARK.json`.
